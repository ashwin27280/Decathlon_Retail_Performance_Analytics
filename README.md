
# Decathlon Retail Performance Analytics

### End-to-End Retail Business Intelligence Solution using Python, PostgreSQL & Power BI

---

## Project Overview

Retail businesses generate large volumes of transactional data every day across multiple stores, product categories, and customer segments. Transforming this data into meaningful insights is essential for improving profitability, optimizing operations, and enabling data-driven decision-making.

This project demonstrates an **end-to-end Retail Business Intelligence solution** for **Decathlon**, where raw retail transaction data is analyzed using **Python**, **PostgreSQL**, and **Power BI** to deliver actionable business insights through interactive dashboards.

---

# Business Problem

Decathlon operates multiple retail stores across different regions and product categories. Although large volumes of transactional data are generated daily, management lacks a centralized reporting system to effectively monitor sales performance, profitability, customer purchasing behavior, and store performance. As a result, identifying high-performing products, underperforming stores, customer purchasing trends, and profitability opportunities becomes time-consuming and limits data-driven decision-making.

The objective of this project is to develop an end-to-end Business Intelligence solution that transforms retail transaction data into actionable insights using **Python**, **PostgreSQL**, and **Power BI**.

---

# Project Objectives

* Analyze overall sales and profitability.
* Identify top-performing and underperforming products.
* Evaluate store and regional performance.
* Understand customer purchasing behavior.
* Perform retail business analysis using SQL.
* Build an interactive Power BI dashboard for decision-makers.
